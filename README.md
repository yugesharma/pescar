# PescaMare

Planning tool for pescatourism in the Azores, built on Copernicus Marine and EU fisheries data
(Copernicus Marine Service Hackathon 2026). Design: [DESIGN.md](DESIGN.md), terms: [GLOSSARY.md](GLOSSARY.md),
decisions: [docs/adr/](docs/adr/), background: [pescatourism_project.md](pescatourism_project.md).

## Run

Needs [uv](https://docs.astral.sh/uv/), Node 20+, and a Copernicus Marine login (`uv run copernicusmarine login`).

```sh
uv run python build.py            # fetch waves, write data/pescamare.db (~2 min)
uv run uvicorn api:app            # API on :8000
cd web && npm install && npm run dev   # app on :5173
```

Self-checks (no network): `uv run python waves.py --test`, `uv run python build.py --test`.

## Data in `data/`

- `fleet_EU_current.csv`: EU Fleet Register, current records of all EU vessels.
- `unlocode.csv`: UN/LOCODE code list (GitHub mirror `datasets/un-locode`).
- `pescamare.db`: generated by `build.py`, not committed.
